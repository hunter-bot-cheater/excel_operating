# 接口文档

| 方法 | 路径 | 请求 | 结果 |
| --- | --- | --- | --- |
| POST | `/api/v1/inspection-reports/generate` | multipart：`bom`、多个 `reports`、可选 `round_no` | 任务 ID |
| GET | `/api/v1/inspection-reports/tasks/{task_id}` | 路径参数 | 任务状态和原汇总 |
| GET | `/api/v1/inspection-reports/tasks/{task_id}/downloads/{filename}` | 路径参数 | 文件流 |
| GET | `/api/v1/health` | 无 | 健康状态 |

任务为进程内串行队列，目的是兼容 Excel COM。鉴权/CORS 是配置预留，未配置生产认证。
