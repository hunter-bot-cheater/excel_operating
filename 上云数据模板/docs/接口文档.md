# 接口文档

| 方法 | 路径 | 请求 | 结果 |
| --- | --- | --- | --- |
| POST | `/api/v1/cloud-templates/convert` | multipart：`file`，可选 `default_year` | 任务 ID |
| GET | `/api/v1/cloud-templates/tasks/{task_id}` | 路径参数 | 任务状态、原转换结果 |
| GET | `/api/v1/cloud-templates/tasks/{task_id}/downloads/{filename}` | 路径参数 | 文件流 |
| GET | `/api/v1/health` | 无 | 健康状态 |

任务为进程内串行队列。CORS、认证开关已配置化，但身份校验需要部署网关或后续鉴权中间件实现。
