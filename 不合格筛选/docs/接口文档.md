# 接口文档

| 方法 | 路径 | 请求 | 结果 |
| --- | --- | --- | --- |
| POST | `/api/v1/nonconforming/screen` | `multipart/form-data`，一个或多个 `files` | `202` 语义的 JSON 包络，含 `task_id` |
| GET | `/api/v1/nonconforming/tasks/{task_id}` | 路径参数 | `pending/running/succeeded/failed`、进度、原函数结果 |
| GET | `/api/v1/nonconforming/tasks/{task_id}/downloads/{filename}` | 路径参数 | 文件流 |
| GET | `/api/v1/health` | 无 | 服务健康状态 |

任务执行串行，原因是原 Excel COM 会话不能安全并发。认证开关仅预留在配置中，尚未实现令牌校验，部署到非受信网络前必须在网关实现认证。
