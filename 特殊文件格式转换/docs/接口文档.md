# 接口文档

| 方法 | 路径 | 请求 | 结果 |
| --- | --- | --- | --- |
| POST | `/api/v1/special-format-conversions/convert` | multipart：`file`，可选 `force_openpyxl` | 任务 ID |
| GET | `/api/v1/special-format-conversions/tasks/{task_id}` | 路径参数 | 任务状态和原函数结果 |
| GET | `/api/v1/special-format-conversions/tasks/{task_id}/downloads/{filename}` | 路径参数 | 文件流 |
| GET | `/api/v1/health` | 无 | 健康状态 |

任务采用单 worker，避免 Excel COM 并发冲突。认证和 CORS 为配置预留，生产部署需要在网关或中间件落实认证。
