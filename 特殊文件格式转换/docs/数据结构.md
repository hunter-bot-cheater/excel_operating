# 数据结构

输入只接受 `.xls/.xlsx/.xlsm`。原解析器从工作簿中提取图号、报告编号、温度、检验人、检验项目、公称尺寸、上下限、读数和结果；字段定位完全由 `legacy/original_src/检验报告模板转换/converter.py` 决定。输出是 `template.xlsx` 布局的 `.xlsx`。

任务对象包含 `task_id`、`trace_id`、`status`、`progress`、`message`、`result`；`result.legacy_result` 是原 `convert_file()` 返回字典，`outputs` 是下载文件路径。新增文本均为 UTF-8。
