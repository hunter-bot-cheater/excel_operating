# 测试与验收

1. 将 `legacy/original_src/检验报告模板转换/test_in` 的每个样例复制到临时目录。
2. 分别用原程序和本项目根目录 `converter.py` 执行，采用相同是否强制 openpyxl 的参数。
3. 对比输出命名、关键表头、数据行、读数范围、上下限 `/`、F/红色、合并区域、行列尺寸、字体边框、图片/对象和 Excel 打开性。
4. 运行 `python -m pytest`。含 `.xls`、复杂格式和 COM 路径须在 Windows+Excel 环境人工复测。

不得对 `D:\特殊文件格式转换` 原始目录运行会产生输出或重命名的命令。
